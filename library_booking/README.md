# ระบบจองโต๊ะและพื้นที่นั่งอ่านหนังสือในห้องสมุด

เว็บแอปจองที่นั่งห้องสมุดสำหรับนักศึกษา เขียนด้วย Python (Flask) และใช้ฐานข้อมูล SQLite
ใช้งานได้ทั้งบนมือถือและคอมพิวเตอร์ กฎทุกข้อถูกตรวจที่ฝั่งเซิร์ฟเวอร์

## วิธีรัน

ต้องมี Python 3.9 ขึ้นไป

```bash
cd library_booking
python -m venv .venv
# Windows:      .venv\Scripts\activate
# macOS/Linux:  source .venv/bin/activate
pip install -r requirements.txt
python app.py
```

เปิดเบราว์เซอร์ที่ http://127.0.0.1:5000 แล้วกด **ใช้บัญชีทดลอง 65011212345**
หรือกรอกรหัสนักศึกษา 11 หลักกับชื่อ เพื่อสร้างบัญชีใหม่

ฐานข้อมูลจะถูกสร้างอัตโนมัติที่ `instance/library.db`
ถ้าต้องการเริ่มใหม่ทั้งหมด ให้ลบโฟลเดอร์ `instance/`

## ฟีเจอร์

| ส่วน | สิ่งที่ทำได้ |
|---|---|
| หน้าแรก | การจองถัดไปพร้อมนับถอยหลังเช็คอิน, โควตาคงเหลือวันนี้, วิธีใช้ 3 ขั้นตอน |
| จองที่นั่ง ขั้น 1 | เลือกวัน (ล่วงหน้า 7 วัน), เวลาเริ่ม (ทีละ 30 นาที), ระยะเวลา |
| จองที่นั่ง ขั้น 2 | แผนผังที่นั่ง 4 โซน 3 ชั้น: เขียว = ว่าง, แดง = มีผู้จอง, เหลือง = กำลังใช้งาน, จุดน้ำเงิน = ของฉัน; กรองตามประเภทโต๊ะ |
| จองที่นั่ง ขั้น 3 | สรุปการจอง, โควตาคงเหลือหลังจอง, กล่องเตือนกฎเช็คอิน 15 นาที, ปุ่มยืนยัน |
| การจองของฉัน | การจองที่กำลังจะถึง, นับถอยหลัง 15 นาที, เช็คอินด้วย QR หรือรหัสนักศึกษา, เช็คเอาท์, ยกเลิก, ประวัติ |

## กฎของระบบ (แก้ได้ที่ `config.py`)

- **โควตา 3 ชั่วโมงต่อวันต่อคน** — ถ้าเลือกระยะเวลาเกินโควตา จะขึ้นหน้าต่างเตือน
  "คุณใช้โควตาเกินกำหนด (สูงสุด 3 ชม./วัน)" และกดไปขั้นต่อไปหรือยืนยันไม่ได้
- **ต้องเช็คอินภายใน 15 นาทีนับจากเวลาเริ่ม** ด้วย QR Code หรือรหัสนักศึกษา
- **ยกเลิกอัตโนมัติ** — เลย 15 นาทีแล้วยังไม่เช็คอิน สถานะจะเป็น "ยกเลิกอัตโนมัติ"
  และโต๊ะจะกลับเป็นสีเขียวทันที ระบบตรวจทุกครั้งที่มีคนเปิดหน้าเว็บ
  ส่วนหน้าเว็บที่เปิดค้างไว้จะโหลดใหม่เองเมื่อหมดเวลา
- 1 โต๊ะจองได้ครั้งละ 1 คน และนักศึกษาจองช่วงเวลาซ้อนกันเองไม่ได้
- ยกเลิกการจองที่ยังไม่เช็คอินได้ และได้โควตาคืน
- ไม่มาเช็คอินครบ 3 ครั้งใน 30 วัน จะถูกระงับสิทธิ์จอง 7 วัน

## QR Code และการสแกนด้วยมือถือ

ทุกการจองมี QR Code จริง สแกนด้วยกล้องมือถือได้ (สร้างด้วย `qr.py` ไม่ต้องติดตั้งไลบรารีเพิ่ม)
กดปุ่ม **ดู QR Code** หรือ **เช็คอินเลย** ในการ์ดการจองเพื่อเปิด QR

- ดู QR ได้ตลอด แต่ระบบจะรับเช็คอินเฉพาะช่วงเวลาเริ่มถึง 15 นาทีหลังจากนั้น
- QR เก็บลิงก์ `/scan/<รหัสการจอง>` สแกนแล้วมือถือจะเปิดลิงก์นี้และเช็คอินให้ทันที
  (มือถือต้องล็อกอินบัญชีเจ้าของการจอง ถ้ายังไม่ล็อกอิน ระบบจะพาไปล็อกอินก่อน แล้วเช็คอินต่อให้)
- ถ้าจะสแกนจากมือถือจริง ต้องรันให้มือถือเข้าถึงเครื่องได้ (ต่อ Wi-Fi วงเดียวกัน):
  ```bash
  # Windows (PowerShell):  $env:HOST="0.0.0.0"; python app.py
  # macOS/Linux:           HOST=0.0.0.0 python app.py
  ```
  แล้วเปิดเว็บบนคอมด้วย IP ของเครื่อง เช่น `http://192.168.1.25:5000` (ดู IP ด้วย `ipconfig` หรือ `ifconfig`)
  QR จะใช้ที่อยู่เดียวกับที่เปิดเว็บ ถ้าเปิดผ่าน `127.0.0.1` มือถือจะเปิดลิงก์ใน QR ไม่ได้
- ถ้าไม่สะดวกใช้มือถือ กดปุ่ม **จำลองการสแกน QR** ในหน้าต่างเช็คอินแทนได้

## โหมดทดสอบเวลา

ท้ายหน้า **การจองของฉัน** มีกล่อง "โหมดทดสอบ" สำหรับเลื่อนนาฬิกาของระบบ ใช้สาธิตได้ทันทีโดยไม่ต้องรอเวลาจริง

1. ตั้งเวลาเป็น 07:00 แล้วจองวันนี้เวลา 08:00
2. กด "ไปที่เวลาเริ่ม" จะเห็นนาฬิกานับถอยหลัง 15:00 และปุ่ม "เช็คอินเลย"
3. กด "30 วินาทีก่อนหมดเวลาเช็คอิน" แล้วรอ หน้าเว็บจะโหลดใหม่และแจ้งว่าการจองถูกยกเลิกอัตโนมัติ

ระหว่างอยู่ในโหมดทดสอบ จะมีแถบสีเข้มด้านบนบอกเวลาจำลอง กด "ใช้เวลาจริง" เพื่อกลับ
นาฬิกานี้มีผลกับทุกคนในระบบ เพราะเป็นเครื่องมือสาธิตเท่านั้น

## โครงสร้างโปรเจกต์

```
library_booking/
├── app.py            # สร้างแอป Flask + เส้นทาง (routes) ทุกหน้า
├── rules.py          # กฎทั้งหมด: นาฬิกา, โควตา, สถานะโต๊ะ, จอง, เช็คอิน, ยกเลิกอัตโนมัติ, ข้อมูลตัวอย่าง
├── database.py       # เชื่อมต่อ SQLite และโครงสร้างตาราง
├── config.py         # ค่าตั้งต้น: โควตา, ช่วงเวลา, ชั้น, ประเภทโต๊ะ
├── helpers.py        # จัดรูปแบบวันที่/เวลาภาษาไทย
├── qr.py             # ตัวสร้าง QR Code แบบ Python ล้วน
├── templates/        # หน้าเว็บ (Jinja2)
│   ├── base.html, _nav.html, _icons.html, _macros.html
│   ├── login.html, home.html
│   ├── book_time.html, book_seat.html, book_confirm.html, book_done.html
│   └── bookings.html, error.html
├── static/
│   ├── css/style.css # ดีไซน์ทั้งหมด (โหมดสว่าง/มืด, มือถือ)
│   └── js/app.js     # นับถอยหลัง, หน้าต่างเช็คอิน, จำลองสแกน QR
├── tests/test_app.py # ทดสอบกฎและทุกหน้า
└── requirements.txt
```

## ทดสอบ

```bash
python -m unittest discover -s tests -v
```

ชุดทดสอบครอบคลุมโควตา 3 ชม., การจองซ้อน, ช่วงเวลาเช็คอิน, การยกเลิกอัตโนมัติ (โต๊ะแดงกลับเป็นเขียว),
การเช็คอินด้วย QR/รหัสนักศึกษา, การระงับสิทธิ์ และการเปิดทุกหน้าผ่านเว็บ

## หมายเหตุสำหรับนำไปใช้จริง

- ตอนนี้เข้าสู่ระบบด้วยรหัสนักศึกษาอย่างเดียว ควรเชื่อมกับระบบยืนยันตัวตนของมหาวิทยาลัย (เช่น SSO)
- ลิงก์ใน QR เช็คอินได้จากที่ไหนก็ได้ ถ้าใช้จริงควรให้สแกนผ่านเครื่องที่จุดทางเข้า หรือตรวจตำแหน่ง/Wi-Fi ของห้องสมุดร่วมด้วย
- การจองของนักศึกษาคนอื่นในแผนผังเป็นข้อมูลตัวอย่างที่ระบบสร้างให้ (ดู `rules.ensure_seeded`)
- ตั้งค่า `SECRET_KEY` เป็น environment variable เมื่อนำขึ้นเซิร์ฟเวอร์ และรันด้วย WSGI server เช่น `waitress` หรือ `gunicorn`
